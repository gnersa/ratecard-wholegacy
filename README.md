# Wholegacy Ratecard v15

Visual-polish release based on review of all four preview designs.

## Highlights
- Unified typography, margins, section spacing, and card density across Modern, Minimalist, Creator Pro, and Dark Pro.
- Rebalanced hero and profile proportions for all themes, especially Creator Pro.
- Stable 2-column social-account layout on desktop and 1-column on mobile, with 3 metric panels per account.
- Better mobile typography with readable statistic labels.
- Mobile collaboration rates render as stacked cards instead of a horizontally scrolling table.
- Contact cards remain side-by-side where practical and collapse on very narrow screens.
- Public creator URL footer is more subtle.
- Consolidated final A4 print rules for consistent PDF output.

No Neon migration is required for v15.
